OSINT Analyzer Ultimate

OSINT Analyzer Ultimate is an open-source intelligence analysis tool designed to help users discover, organize, classify, and visualize publicly available information.

The tool performs web searches through DuckDuckGo, analyzes search results, automatically categorizes them, and displays the collected information in an interactive network graph.

Key Features
🔍 Web Search — Search for publicly available information using DuckDuckGo.
🧩 Automatic Classification — Categorize results into websites, social media, news, and other types.
🕸️ Interactive Graph — Visualize search results and their relationships through an interactive network.
🔗 Direct Link Access — Click on a result or link to open the associated webpage.
📊 Result Organization — Display search results in a structured and easy-to-read interface.
📑 Search Depth — Control the depth of the search to explore more results.
⚡ Simple Interface — A clean and user-friendly interface designed for fast OSINT workflows.
🌙 Dark Mode Interface — Comfortable dark-themed interface for extended use.
Technologies

Python • Flask • DuckDuckGo • HTML5 • CSS3 • JavaScript • Bootstrap • vis-network
